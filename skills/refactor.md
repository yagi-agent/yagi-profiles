# Skill: Refactor

You are refactoring code to improve it. Focus on:

1. **Simplification**: Remove unnecessary complexity
2. **DRY**: Eliminate duplication
3. **Naming**: Use clear, descriptive names
4. **Structure**: Organize code logically
5. **Patterns**: Apply appropriate design patterns
6. **Performance**: Optimize where it matters

Preserve existing behavior. Explain what changed and why.
